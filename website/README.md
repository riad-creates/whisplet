# Whisplet landing page

Next.js static export. Install dependencies with `npm ci`; use `npm run dev` for
local development, `npm run lint` and `npm test` for validation. `npm run build`
exports to `out/`; no Node server is needed to serve the exported page.

The landing page has a copyable automatic setup command and links to the GitHub source-build guide. It does not advertise a
notarized binary or automatic updater. Its illustrated note is fictional content.
The Sites project is recorded in `.openai/hosting.json`. Keep source credentials
out of files and Git. The hosted site is public; preserve its existing access.
